## 📜 Code of Conduct & House Rules

1. **Be Cunning, but Kind:** We value sharp technical execution, ambitious ideas, and constructive, supportive discourse.
2. **Respect the Privacy Protocol:** Never commit hardcoded API keys, private chat logs, or persistent audio recordings. All audio must follow the volatile memory zero-retention standard.
3. **No Dark Magic (Unchecked Dependencies):** Keep dependencies lean, secure, and well-tested.

## ⚡ Development Workflow

### 1. Fork & Branch
```bash
git checkout -b feature/slug-club-enhancement
```

### 2. Local Environment Setup
```bash
# Python Backend
pip install -r backend/requirements.txt

# React Frontend
cd frontend
npm install
cd ..
```

### 3. Run Automated Tests
Before submitting any pull request, ensure all tests pass cleanly:
```bash
python -m pytest backend/tests/
```

### 4. Build Frontend Bundle
```bash
cd frontend
npm run build
```
